Is the neighbourhood shop open?

A Bengaluru-first application connecting shop discovery with owner-updated availability.

01Problem

A listing with opening hours cannot always answer whether a nearby shop is actually open right now. Customers need current status and useful alternatives.

02Approach

NammaOpen connects a mobile-first PWA to a FastAPI backend, shop discovery services and SQLite storage. Bot webhook flows support owner onboarding and status updates; pilot seed data supports local exploration.

03Results

The repository contains a runnable local MVP, public shop pages, API endpoints, seed data and smoke tests. Before a public launch, the next steps are provider verification, authentication, rate limiting and notification delivery.
