Playlists that travel with the drive.

A small Python tool that organises media for VLC on Android TV.

01Problem

Absolute media paths break when an external drive moves between devices or receives a different drive letter. Manually maintaining playlists also becomes tedious.

02Approach

The CLI scans explicitly supplied folders, filters common extras, infers categories and writes M3U playlists with relative POSIX-style paths. Optional ffprobe metadata adds resolution and audio information.

03Results

The public utility generates category playlists without Python package dependencies. Relative paths keep playlist references portable with the folder structure; filename-based classification remains heuristic.
